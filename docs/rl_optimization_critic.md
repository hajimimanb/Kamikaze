## 2. 逐条评估（预期效果 / 风险 / 创新度 / 决策）

### 2.1 架构候选 A1~A6

#### A1 事件 recency 升级（padding mask + 巡目/相对距离 + 多头池化）——**采用（拆分）**
- **预期效果**：✅ 合理。padding mask 是 transformer 序列建模的**标准正确性要求**（补零 token 参与 attention 会稀释有效事件权重；本实现 causal mask 只防未来、不防补零）。last-token 单点输出在"最后事件恰为无关事件"时信息丢失，last+mean-pool（掩码平均）或 learnable query 是 BERT/T5 等广泛验证的输出聚合方式。相对距离/计数通道是 recency 归纳偏置（相对位置编码家族，T5/ALiBi）。
- **风险**：低。旁支随机初始化重训无兼容负担；唯一注意点是 mean-pool 必须按 padding mask 平均，否则补零拉低均值。
- **创新度**：低-中。通用 transformer 技术，麻将领域无直接对应先例（Suphx/Tjong 的 transformer 未见"事件级 recency 计数 + 补零掩码池化"的明确描述）；对本代码库是实质改进，对领域是工程性增强。
- **决策**：**采用**，但拆成两个提交：① padding mask = 正确性修复（必修，独立验证）；② recency 通道 + 池化输出 = 增强（可消融归因）。修改意见见 §3-A1。

#### A2 输入相关门控 —— **后置消融**
- **预期效果**：⚖️ 方向合理但收益不确定。静态 gate 确实等价于对角缩放折进 out 投影；输入相关 gate 允许按局面（ctx 即局面摘要）调节注入强度。但 trunk 50 块深度本身有强表征能力，门控从"常量"变"函数"的边际收益需要 A/B 验证，方案定位为消融项是稳妥的。
- **风险**：低（+~20K 参数）；需保初始 σ≈0.1 防旧权重被扰。
- **创新度**：低。gating/GLU 是通用结构；无麻将特定先例（Suphx 无此机制），但也不构成领域创新。
- **决策**：同意**后置消融**（v1 达标后）。修改意见见 §3-A2。

#### A3 多深度注入 —— **后置消融（先做单点扫描）**
- **预期效果**：⚖️ 不确定。特征金字塔多尺度在视觉任务有效的前提是**多分辨率输入**；此处是"同一 ctx 向量注入多层"，残差网络的信息穿透能力远强于视觉骨干，收益可能被 trunk 掩盖——方案自己也承认（"收益可能被表征能力掩盖"）。
- **风险**：调参面增大。
- **创新度**：低（layer-wise 注入常见）。
- **决策**：同意后置消融，但建议**先做"注入深度单点扫描"**（浅/中/深 3 点各短程训）再决定是否多深度注入，避免消融矩阵爆炸。见 §3-A3。

#### A4 事件 token 完整化 —— **采用（维度方案必须修正）**
- **预期效果**：✅ 合理且重要。副露组成（345 vs 456）决定吃牌家听牌范围（阶段 2 ③ 的核心输入信号）；杠后宝牌翻转是弃牌风险突变（dora 变化直接影响放铳风险）；立直时机/一发巡有信息量。JongMaster 的防守改进（减放铳 5.12%）说明"对手信息精细度 → 防守收益"的链路真实存在。
- **风险**：中。① **方案自相矛盾**：§A4 写"event_dim 46→~60"却又写"副露组成 3×34 稀疏"——3×34=102 维，加被叫牌等 >110 维，不可能塞进 ~60（修正方案见 §3-A4，用 34 维 OR 编码，总维度 ~84）；② build_events_from_game 与 build_events 双处必须同步维度，否则离线回退/评估侧崩；③ 轨迹 events float16 (64,46)→(64,84) 存储 +30%，可接受。
- **创新度**：中。领域表示设计；Suphx 的输入编码（含他家手牌信息用于 oracle）更"全知"但那是训练期特权；Tjong 的 "fan backward"（向后推理和牌番数）与本项"杠后宝牌/听牌范围"信息编码方向相关但不同。无直接复制。
- **决策**：**采用**（与 A1 合并实施，维度修正后 1.5~2 人·天）。修改意见见 §3-A4。

#### A5 声明阶段联合多分类头 —— **后置独立消融**
- **预期效果**：✅ 合理。声明本质是互斥选项联合选择（同张牌可 ron 也可 pon/kan），独立 sigmoid×归一化无法表达 ron-vs-pon 的代价权衡；对**合法选项集合**做 softmax 是 AlphaStar action-masking 的标准做法，样本效率更高（每声明步同时更新全部选项）。JongMaster 用 5 个**分离**模型（Discard/Chow/Pong/Kong/Riichi）反而是联合头改进空间的旁证。
- **风险**：中——触及 logp/重放正确性核心路径（test_rl_grads 3 断言刚修绿），且声明步样本极少（每局 0~5 步），联合头在样本不足时未必优于 sigmoid 近似。
- **创新度**：中低（action masking 标准；麻将领域 Suphx 的声明处理也是独立输出，未见联合合法集 softmax）。
- **决策**：同意**后置**（v1 过 66% 后独立消融，不阻塞首训）。见 §3-A5。

#### A6 阈值温度"学习化" —— **放弃（与 T5 二选一，选 T5）**
- **预期效果**：⚖️ 方向对（阈值应随策略演化再校准）但手段弱。
- **风险**：中——可辨识性问题：logit 尺度与温度在联合训练中不可分离，τ 与 logit 可能互相抵消/退化；3 个标量的收益上限低。
- **创新度**：低（learned temperature 是已知 trick）。
- **决策**：**放弃**，采纳 T5（数据侧重校准更便宜、可审计、零训练风险、可回滚）。理由：同一目标（决策面随策略演化保持代价最优）下，T5 以更低成本、更低风险达成，A6 无独立价值。

### 2.2 训练候选 T1~T11

#### T1 奖励尺度对齐 + settlement_pt 接线 + Φ 监控 —— **采用（修改）**
- **预期效果**：✅ 最高优先级，成立。auditor G 已实锤 value(±25) 与奖励(±0.02) 失配 → GAE 被 V 主导；settlement_pt 已实现（rl_reward.py:62-83，tenhou 配置，避 4 不对称正确进入奖励）。Φ 差分奖励 = Suphx GRP（informative reward）的直接复制——先例充分（Suphx §3）。
- **风险**：低，但"轮得分差 × 1000"过渡常数是**拍脑袋**：当前 r=Δscore/100000，Δscore 典型 ±1000~±8000，×1000 → ±1e6~8e6 量级，**比 value ±25 大 4 个数量级，方向相反的错误**。必须以"尺度核对"定常数（见 §3-T1）。
- **创新度**：低（=Suphx GRP 接线，正确性修复而非创新）。
- **决策**：**采用（必做，开训前）**，但过渡常数与验证方法必须按 §3-T1 修正。工作量 0.5~1 → **1~1.5 人·天**（接线 + 尺度核对 + Φ 监控脚本 + 触发逻辑）。

#### T2 稀有动作重加权/分层采样 + 熵掩码 —— **采用（修改）**
- **预期效果**：✅ 成立且高 ROI。类不平衡已核验（~90% discard；binary 头每局 0~5 样本；熵对不可用头无条件计算）。loss 加权（不改采样）无偏、ratio 不受影响，安全；过采样需重要性比修正，风险更高。JongMaster 按动作类型分离模型其实是对类不平衡的另一种解法，说明该问题真实且值得处理。
- **风险**：中低。**熵掩码的副作用必须处理**：chow/pon/kan 在大多数步非法，若掩码后这些步熵记 0 而归一化分母仍用全部行 → H_bar 被稀释失真（现有 discard 分支已用"全非法记 0"规避 nan，但 binary 头加掩码后需同步调整分母）。
- **创新度**：低（类不平衡加权、熵掩码均为标准实践）。
- **决策**：**采用（必做）**：先 loss 加权 + 熵掩码（无偏、低风险），过采样后置。修改意见见 §3-T2。

#### T3 对手课程 + 池 + 锦标赛 —— **采用（拆两段）**
- **预期效果**：✅ 成立。RandomOpponent-only 已核验；纯随机对手学不到防守（对 SL 验收是负迁移），纯 SL 前期太难。课程/对手池/锦标赛 = 标准自对弈实践（Suphx 自对弈+固定对手、AlphaStar league 的简化版）；Suphx 的 5 模型投票与固定对手集合本身就是防坍缩手段。
- **风险**：中——锦标赛局数/K 是超参；早退 ckpt 污染对手分布。
- **创新度**：低（self-play curriculum/league 标准；麻将领域 Suphx 已触及）。
- **决策**：**采用**，但**先做"随机→SL 两段课程"**（0.5~1 人·天，拿大部分收益），对手池 + 锦标赛后置（+1 人·天）。见 §3-T3。

#### T4 温度/熵课程 —— **采用**
- **预期效果**：✅ 合理。标准探索调度；熵自适应目标（arch §7.4/§7.7）已有，T4③ 与其一致（注意别与 α 自适应双重过调——见修改意见）。
- **风险**：低；需监控 H_bar 与 gate 均值联动。
- **创新度**：低（温度退火/熵目标标准）。
- **决策**：**采用**。见 §3-T4。

#### T5 阈值再校准循环 —— **采用**
- **预期效果**：✅ 成立且便宜。策略演化 → logit 分布偏移 → 固定 SL 阈值的决策面次优（tsumo 0.86 可能错杀 RL 学到的低调自摸）；数据侧重校准（temperature scaling / 代价敏感阈值）是标准 ML 校准实践，复用现成 SL 校准工具链。
- **风险**：低；tsumo 负样本不足时保持旧阈值（方案已提，正确）。
- **创新度**：低-中。校准本身是标准；"RL 训练中每 epoch 重校准阈值并写 ckpt 元数据"在麻将 RL 文献中未见明确先例（Suphx 的和牌决策含规则式成分，无此机制）——算本领域小创新/工程改进。
- **决策**：**采用**。见 §3-T5。

#### T6 KL 锚定 SL + 人类数据混合 —— **采用（KL 必做，人类混合后置）**
- **预期效果**：✅ 合理。无锚自对弈初期漂移风险真实；KL 锚定/行为约束有充分先例（TRPO 类 KL 约束、AlphaGo SL 初始化+自对弈、RLHF KL 正则）。人类数据 28K 局现成。
- **风险**：中低——KL 过重封顶改进上限（衰减解决）；人类混合的 BC loss 与自对弈分布混批需注意（方案已用 BC 而非 PPO reward，正确）。
- **创新度**：低（KL 正则标准；Suphx 的 oracle-dropout 渐进退火其实承担了类似"锚定→放开"的功能，但机制不同）。
- **决策**：**采用**（KL 0.5 人·天必做；人类混合 0.5 视时间，且需 SL 标签→RL action 结构转换成本）。见 §3-T6。

#### T7 潜在整形 —— **后置消融**
- **预期效果**：⚖️ 合理但边际收益存疑。Ng 1999 potential-based 保最优策略不变（理论正确）；hand_value_discard 现成且引擎级准确。但 T1 落地后 Φ 差分已提供每轮稠密信号，T7 的增量有限；且"仅听牌段非零"意味着前期无信号。
- **风险**：中——启发式噪声；需保证 potential 用同一 F 函数。
- **创新度**：低（standard shaping；Suphx informative reward 同类思想）。
- **决策**：同意**后置消融**（T1 后若弃牌收敛仍慢再上）。见 §3-T7。

#### T8 多进程 + 批量推理 —— **视资源，先做 4 座同批**
- **预期效果**：✅ 工程吞吐，评审 §3 的 30~80→3~15 GPU·时 数据支持。
- **风险**：工程量大（进程通信/边界处理）。
- **创新度**：低（工程）。
- **决策**：**视资源**；若做，先"4 座位同批 GPU 推理"（~0.5~1 人·天，4× 吞吐，改动小），async 多进程后置。见 §3-T8。

#### T9 评估协议增强 —— **采用**
- **预期效果**：✅ 成立。仅 SL 单一基线 + 训练中只看自对弈胜率 = 自证循环；vs-random sanity（0.375 参考线）与 human agreement 趋势监控能在早期发现退化，成本低。Suphx 用天凤段位对战评估，本项是低配版同思路。
- **风险**：低；human agreement 有天花板（~77%）只作趋势。
- **创新度**：低（评估实践标准）。
- **决策**：**采用**。见 §3-T9。

#### T10 局况条件化 adv 归一化 —— **采用**
- **预期效果**：✅ 合理。Suphx §3.2 的确指出麻将奖励的局况非平稳性（同点差在领先/落后、早巡/晚巡价值不同）；分组归一化降低方差、改善避4/追分学习。
- **风险**：低（~10 行）；分组桶数需调、小样本组需 guard。
- **创新度**：低（conditioned normalization 变体）。
- **决策**：**采用**。见 §3-T10。

#### T11 hindsight 价值回填 —— **暂缓（阶段 3 前再评估）**
- **预期效果**：⚖️ 与 Φ 差分奖励信息重叠（Φ 已在做"终局已知 → 逐轮价值"），阶段 1 优先级低，同意暂缓。
- **决策**：同意**暂缓**；阶段 3 做剥削性打法时再评估（与 Φ 重训同源思想可复用）。

### 2.3 ③④ 增量修正清单 —— **采纳（阶段 2 范围）**
- **③-1/④-1 相对座位序编码：关键且正确**。日麻中下家/对家/上家的相对座位序决定鸣牌优先级（下家优先）与轮转；**纯 3 家全置换等变丢失该结构**。注意：Suphx 的 seat invariance 是**循环旋转（cyclic）等变**——cyclic 保持相对顺序，与"全置换等变"不等价。若本仓库 OpponentEquivariant 是全置换等变，则它比 Suphx 更强的对称性假设**更激进且丢失更多信息**，修正意见（seat-relative / 相对座位 one-hot）方向正确。这是本方案最有价值的架构发现之一。
- **③-2 危险度 = tenpai × 待牌概率分解**：✅ 合理。可解释、可用自对弈 ground truth 直接监督（他家手牌已知）；比直接回归 34 维危险度好学好检。JongMaster 减放铳 5.12% 是"防守可学"的直接证据。
- **③-3 信念概率再校准**：✅ 同 T5 思路，采纳。
- **④-2 对手风格摘要 FiLM**：阶段 3 剥削前置，采纳（阶段 1 预留 summary 通道即可）。
- **④-3 鸣牌反应预测 aux head**：✅ 可行（引擎 claim_queue 可给 ground truth），是防守读牌的直接训练信号。

## 3. 采用条目的具体修改意见（可操作）

### §3-T1 奖励尺度对齐（必做）
1. **废除"轮得分差 × 1000"过渡**（量级方向错误，见 §2.2-T1）。改为：**先写尺度核对脚本**（train_rl --smoke 打印 value 输出均值/标准差、轮奖励均值/标准差、终局 settlement_pt 分布），把 reward 与 value 统一到同一量级；验收条件：|E[r]| 与 E|ΔV| 比值落在 0.2~5 内。
2. **推荐统一常数方案**：终局 = settlement_pt（原样，±20~60）；轮间 = Φ 差分（Φ 输出即 settlement_pt 尺度）；过渡（Φ 未就绪）= Δscore/100（8000→80，仍偏大）**或直接复用 Φ 已训练 ckpt**——优先用 reward_predictor.pt（已存在 checkpoints/sl/rl/），过渡常数只作为最后兜底且必须经核对脚本。
3. value_pretrain 若仍以 ±25 为目标则保持（与 settlement ±20~60 同量级，无需重归一化）；若核对发现失配 >5×，对 value 输出层乘固定 scale（不动预训练权重）。
4. Φ 监控脚本：先记录初始基线（reward_predictor 在 eval 日志的 MSE），每 500 局对比，>30% 恶化触发重训；每 2000 局重训，数据 = 50% 最新自对弈 + 50% 人类日志（防遗忘）；重训 lr 1e-4 ~500 步。

### §3-T2 稀有动作重加权 + 熵掩码（必做）
1. **先做 loss 加权**：权重 w_h = clip(1/稀有度_h, 1, 8)（稀有度按最近 2000 局统计），只乘在 policy loss 上、不改采样分布 → 无偏、ratio 不变、test_rl_grads 不受影响。
2. **熵掩码**：对 riichi/chow/pon/kan 只在"该头该步合法"行计算熵，非法行记 0；**归一化分母同步改为"合法行数"**（H_bar 的分母 = 5 头合法行比例加权，防稀释）。ron/tsumo/kyushu 维持不入熵（arch 现状）。
3. 过采样后置：若 loss 加权后稀有头仍学不动，再过采样，且 PPO importance ratio 需按实际采样分布修正（用 p_behavior 而非 on-policy 近似），测试成本 +0.5 人·天。
4. 加监控：每 epoch 输出各头正样本数 / loss 构成占比。

### §3-A1 事件 recency 升级（拆两提交）
1. **提交 1（必修，纯正确性）**：EventCausalAttn 加 key_padding_mask（补零位置 -inf），与 causal triu 组合；mean-pool 时按掩码平均真实 token。独立跑验收 + smoke，预期不改策略行为只除噪声。
2. **提交 2（增强，可消融）**：token 附加标量通道——巡目计数（本轮第几次打牌，跨轮重置）、立直后手切数、距当前步相对事件距离；输出 = last-token + mean-pool 拼接（或 learnable query 池化）。
3. 消融设计：mask-only vs mask+pool vs mask+pool+count 三档，同 seed 各跑验收 v2（100×3），归因清晰。
4. 注意：A2 后置时 gate 输入应取"升级后的 ctx"。

### §3-A4 事件 token 完整化（维度方案修正）
1. **放弃"3×34 稀疏"**（102 维不可行）。改用：**34 维 OR 编码**（吃牌=3 张不同 kind 的顺子，OR 完全区分 345 vs 456；碰/杠=单 kind，OR 亦完备）+ **被叫牌标记 1 维** + **杠后宝牌翻转 1 维**（kan 事件 token 置位；或引擎事件流允许则新增 dora-flip 事件 token）+ **立直时机 1 维**（第 N 次摸牌立直，跨轮重置）+ **一发巡 1 维** → event_dim 46→~84。Linear(46→256) 参数仅 +~9.7K，可忽略。
2. build_events_from_game 与 build_events **双处同一 schema**；smoke 断言两处输出维度一致。
3. 轨迹 events float16 (64,84) 存储 +30% 可接受；无历史轨迹兼容问题（RL 尚未开训）。
4. 在 kan 事件后若引擎无 dora 事件，用"kan token 上的翻转 bit"实现，评估/部署同路径。

### §3-T5 阈值再校准
1. 校准集 = 最近自对弈轨迹的自然正负样本（ron/tsumo 正样本 = Bernoulli 采样下实际执行该动作的步）。
2. 代价敏感 Cfp=5/10（复用 SL 校准工具链）；tsumo 正样本 <200 保持旧阈值（SL 同款保护）。
3. 每 epoch 末写入 ckpt 元数据（thresholds/temps + 校准日期 + 样本量）；评估/验收用同一版本阈值保证可比。
4. **回滚条件**：校准后验收 win_rate 下降 >2pt → 回滚上一版阈值。

### §3-T4 温度/熵课程
1. 温度只影响 sample_with_logp 采样，**不得改动 act()**（验收固定阈值语义）；实现时确认两路径温度参数解耦。
2. discard 与 binary 头温度分开（discard 易塌缩，单独退火到 0.7，binary 保持 1.0 或更低上限）。
3. 熵目标：T4③ 的"衰减到 0.9×SL 熵"与 arch 的 α 自适应**只取一个主控**（建议保留 α 自适应，T4③ 作为上限约束而非主曲线），防双重过调；监控 H_bar 与 gate 均值联动。

### §3-T10 局况条件化 adv 归一化
1. 分组键 = (顺位, 半庄段[前半/后半]) 起步 8 组；每组样本 <50 回退全局归一化。
2. 归一化位置：GAE 之后、policy loss 之前（现 ppo_update 全局归一化行替换）；value loss 用未归一化的 returns（不变）。
3. 消融开关 --adv-grouped 默认开，A/B 可关。

### §3-T9 评估增强
1. vs-random：固定 seeds + 固定 random 策略，输出 mean±CI 与 0.375 参考线（复用 eval v2 结构）。
2. human agreement：**固定 200 局面**（不滚动换样本，保证趋势可比）；指标 = discard top-1 一致率 + 声明决策一致率；每 500 局记录（与 Φ 监控、自对战同节奏）。
3. 只作趋势监控不作门槛（天花板 ~77%）。

### §3-T3 对手课程（拆两段）
1. **先上两段课程**：epoch 1~2 随机对手混合（探索）→ 之后 SL(transfer_final) 主对手。切换不按固定局数，按"对 SL 胜率"自适应：随机对手权重 = clip(1 − wr_vs_sl/0.66, 0, 1)。
2. 对手池后置：top-K（K≤8）checkpoint，选择用 mini-tournament（vs SL 20 局 + vs random sanity 10 局）排名，**不随机抽样**；剔除与当前策略差异过近的 ckpt（防早退污染）。
3. 锦标赛成本预算：每 epoch K×30 局 ≈ 240 局，约占训练量 2~3%，可接受。

### §3-T6 KL 锚定
1. KL 只对采样头（discard/riichi/chow/pon/kan）计算；ron/tsumo/kyushu 阈值头无分布可比，不算。
2. 权重 w = 0.1 × (1 − epoch/E) 线性衰减到 0（或指数 0.1·0.5^(epoch/2)）；监控 KL 值与 w 联动。
3. 人类混合后置：BC loss = CE(π_rl, label)，混入 10~20%；**注意 records 是 SL 标签格式，需转 RL action 结构**（含 claim 联合分布的标签映射，+0.5 人·天）；混合权重同 KL 衰减。

### §3-A2 输入相关门控（后置消融）
1. 初始化：末层 Linear 权重 0、bias −2.2 → σ≈0.1（与现 -2 同量级）；加残差旁路（gate 恒等时 = 静态 gate 行为）保证消融基线可比。
2. gate 输入 = tanh(升级后 ctx)（A1 落地后）；A/B：static vs input-dependent 同 seed 验收 v2。
3. 监控：gate 均值/方差 + 与局面特征的相关性（立直攻防/副露压力局面下 gate 是否分化）。

### §3-A5 声明联合头（后置）
1. ClaimHead 输出 logits 仅覆盖**实际合法选项集合**（{pass, ron, kan?, pon?, chow?} 按 claim_queue 优先级）；logp 走同一函数（单一数据源不变）。
2. 前置条件：test_rl_grads 3 断言全绿（含双选项 logp 一致、ratio=1）；消融与独立 sigmoid 同 seed 对比。
3. 与 T2 联动：声明步样本少，联合头消融应在 loss 加权之后做，否则样本噪声淹没结构收益。

### §3-A3 多深度注入（后置）
1. 先做**单点深度扫描**：注入点 ∈ {第 15/35/50 块} 各训短程（~500 局）+ 验收，选最优单点；若三点无差异 → 放弃多深度注入（说明 trunk 穿透力足够），省下 1 人·天。
2. 若扫描有差异 → 再做"多深度 = 最优单点 ± 相邻层"的消融。

### §3-T7 潜在整形（后置消融）
1. potential 必须用**同一个 F**（F(s') − γF(s) 用同一 hand_value_discard 函数），保 Ng 1999 保优性。
2. 只对 discard 步加；shaping 奖励正常进 GAE（potential-based 下 critic 会吸收，无需特殊处理）。
3. 消融条件：T1+T2 落地后跑 1 epoch 看弃牌收敛速度，仍慢再上 T7。

### §3-T8 吞吐（视资源）
1. 先做"4 座位同批 GPU 推理"（rollout 内 4 局 batch 前向，~0.5~1 人·天，4× 吞吐）。
2. async 多进程后置（与 T2 池化联动时**先同步池化、再异步化**，避免同时引入两个复杂机制）。

## 5. ROI 排序复核与工作量修正

**ROI 排序总体同意**（正确性 > 采样 > 架构 > 工程），三点修正：

1. **A4 工作量 1 → 1.5~2 人·天**：维度升级涉及双处 build_events 同步、轨迹存储格式、smoke 断言，且原方案维度自相矛盾需重设计（§3-A4）。

3. **T3 拆分**：两段课程 0.5~1 人·天（M1 必做）；池+锦标赛 +1 人·天（后置）。

修正后总预算：M0 约 **7~8 人·天**（原 6），M1 约 2~2.5 人·天，合计 9~11 人·天（原 7~9）。

**创新度总评**：25 个候选中约 20 个是"标准技术在本代码库的正确落地"（熵掩码/padding mask/KL 锚定/temperature scaling 校准/potential shaping/adv 分组归一化/课程对手池/多进程），**没有一个是研究级新方法**；真正的领域差异化在 ② 事件因果注意力（Tjong 无）、③④ 的麻将表示（相对座位序、副露组成、危险度分解）与阶段 3 剥削（麻将空白，roadmap 已定）。因此：
- 对 66% 门槛贡献最大的是**正确性修复**（T1/T2/A1-mask/T9-sanity），它们是"把该做的做对"，不是创新；
- 建议 M0 内部明确分两组：「必修正确性」（T1/T2/A1-mask/T9）与「增强」（A1-recency/A4/T5/T4/T10），先修正确性并复跑 smoke+验收，再逐项叠加增强并独立归因，避免"一起上、坏了一个不知道是谁"。
