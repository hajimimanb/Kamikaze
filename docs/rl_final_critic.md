## 1. 创新度评估（对照 Suphx / Tjong / JongMaster / mahjonglm / mjai.app）

### C1 事件因果注意力（草案 §C1）—— 真新（组合级），表述需精确化
- **对照核验**：Suphx 无事件注意力（CNN 主干）✅ 属实；Tjong（CAAI TIT 2024）用静态帧 transformer，无事件时间线因果建模 ✅ 属实；JongMaster 用 CNN+LSTM+SA，无事件因果结构 ✅ 属实。
- **风险点**：mahjonglm（2024）/ LLM 打牌（2509.01328）已做麻将序列建模，"attention 用于麻将"本身不新。草案"**麻将 AI 首次**"若按字面会被审稿人抓。
- **裁定**：主张精确化为——"麻将 AI 中**首次将公开事件时间线显式建模为因果序列**（事件级 token + 因果掩码 + recency 计数 + 逐通道门控融合）（据我们所知）"。组合级首次成立，不是"attention 首次"。

### C2 信念危险度分解（草案 §C2）—— 真新（方法级）
- **对照核验**：JongMaster 只做整体防守改进（放铳率 -5.12%），无"危险度 = P(听牌)×P(待牌)"的显式分解 ✅；麻将 AI 无此先例 ✅（roadmap 调研 Mortal/AlphaJong/Naga/kanachan/Hydra 均无）。
- **支撑证据**：直接监督来源真实（roadmap D2：自对弈 ground truth + 数据集 mask 自家手牌）；gen_danger_data.py 已有 18.7K 点验证。
- **裁定**：真新。但"分解"作为方法贡献必须证明**分解本身**有用（vs 单一整体危险度头），否则只是实现细节——见 §2 表2 修改。

### C3 相对座位序等变（草案 §C3）—— 真新（分析级），需形式化
- **对照核验**：Suphx 是 cyclic 旋转等变（参数共享）✅ 属实；"全置换等变丢失下家/对家/上家相对顺序结构"是我 critic 已认定的关键架构发现，草案升级为理论贡献方向正确。
- **风险点**："首次系统分析"需要形式化支撑：至少给出严谨的信息结构论证（全置换 vs cyclic 各自保留/丢失什么信息、鸣牌优先级为何依赖相对顺序），最好有命题级陈述。否则审稿人视为"观察"而非"分析"。
- **裁定**：真新（分析型），形式化深度决定贡献等级。效果指认"样本效率"必须操作化（见 §2）。

### C4 阶段3 剥削（草案 §C4）—— 真新（领域空白），收益不确定已如实定位
- **对照核验**：麻将领域无显式对手建模/剥削 ✅（roadmap 调研）；poker 有 Libratus/Pluribus 先例，麻将未见 ✅。
- **裁定**：真新，作为 bonus section 定位正确（收益不确定，不赌论文主线）。

### C5 RiichiBench（草案 §C5）—— 资产真实，**"首个"声称必须修正**
- **关键事实（本次核验新增）**：docs/mjai.app-main/README.md 明确——**mjai.app 是麻将 AI 竞赛平台（mahjong AI competition），且已于 2026-04-30 退役，迁移至 riichi.dev**。即"标准化麻将 AI 评测"并非空白，"首个"按字面不成立。
- **修正定位**：**"首个决策级标准化基准（据我们所知）"**——差异化点不是"有评测"，而是：55.9M 决策点 + oracle 99.95% 验证引擎 + 分层协议 L0-L4 + 校准方法论 + 可复现 leaderboard harness。并在 related work 明确对照 mjai.app/riichi.dev（差异：bot 对战评测 vs 决策点基准；mjai.app 退役恰是生态空窗，引用时须指向 riichi.dev 现状）。
- **数据真实性**：55,950,217 决策 / 110,254 局（data_report.md）与草案一致 ✅。oracle 99.95% 需复核统计粒度（见 §2-C5）。

**创新度总评**：C1-C4 均为真新（无虚创新），C5 资产真实但声称需修正。草案 §0"诚实评估 70/100"与其一致。

## 2. 效果评估（每项：证据 / 失败风险 / 缺口）

### 效果铁律四条（草案 §0）—— 与我 R5 完全对齐，予以确认
效果指认 + 独立消融（CI）+ 阶段门槛 + 正确性优先：与我的"开训前定义创新点成立标准"要求一致。补充一条：**每项创新设"最小可报告效应量"**（如 top-1 +0.3pt 或放铳率 -2%，且 CI 排除 0），低于则自动降级附录——比"CI 跨 0"更严，防"统计显著但量级无意义"。

### C1：预期 top-1 +0.3~1.0pt —— 量级合理，但缺 RL 期指认
- **证据**：recency/相对位置编码在 transformer 的典型增益量级（T5/ALiBi 经验），作为规划量级合理。
- **失败风险**：低-中。recency 对麻将弃牌的边际收益可能接近 0；消融 CI 判定已兜底。
- **缺口**：效果指认只有 SL top-1 + 解释质量，**未给 RL 阶段效果**。补：RL 阶段信息密度提升 → 防守质量（放铳率/被直击损失），或明确"C1 主效果 = SL top-1 + 解释质量，RL 期为间接收益不作主主张"。

### C2：放铳率 -3~5% 且胜率不降 —— 合理，但缺"分解消融"行
- **证据**：JongMaster 参照 -5.12% ✅ 量级锚定合理；"胜率不降"硬约束已写入 R-B 回滚 ✅。
- **失败风险**：中。防守改进经典副作用 = 过度保守致胜率降，回滚机制已覆盖。
- **缺口（重要）**：草案表2 只有 ③ on/off。**必须加"危险度分解 vs 单一整体危险度头"消融行**——这是 C2 作为"方法贡献"的关键证据（证明分解本身有效，而非仅"加了危险度头有效"），否则审稿人可判"分解是实现细节"。

### C3：样本效率 + 声明一致率 —— 最弱指认，必须操作化
- **证据**：等变归纳偏置提升样本效率是机器学习通识，方向成立。
- **失败风险**：低（"不降效果"即可守住），但"样本效率提升"若无法展示就是空话。
- **缺口**：操作化为——同训练预算下（1）收敛曲线对比（达到目标一致率的步数）、（2）最终声明一致率/胜率对比，并给出三档等变（全置换/cyclic/seat-relative）的同 seed 消融。理论贡献本身不强求大幅效果，但必须展示 seat-relative 不降效果且提升声明一致率。

### C4：风格化对手池 +3~5% 且均衡基线不降 —— 合理，**缺池外泛化守门**
- **证据**：剥削收益在 poker 已验证（Libratus/Pluribus），量级规划合理。
- **失败风险**：高（4 人互制衡 + 池内过拟合）。草案 R-F 只写了"收益不足如实报告"——**不够**。
- **缺口（重要）**：加硬守门——**对池外对手（holdout 风格池 + 至少一个外部 bot）不显著退化（胜率 CI 下界 ≥0.48 之类）**。只对训练池提升 + 对均衡基线不降，仍可能"过拟合对手池"（rock-paper-scissors 陷阱）。这是我 R4 的核心要求。

### C5：不直接提升模型效果 —— 定位正确，需合规闸门 + 口径复核
- **证据**：55.9M/110K 真实 ✅；oracle 证据存在（443 测试 + 78/78 + 30/30 独立验收）✅。
- **失败风险**：中。① 天凤数据再分发许可不明（Suphx 都不公开数据）——**发布合规是硬闸门**，未通过则切换"特征级决策点"或"引擎自对弈生成数据"（完全自有版权）方案；② 99.95% 的统计粒度（按事件/按局/按结算？）写入数据卡前必须复核钉死——这是 benchmark 可信度基石。

**效果总评**：草案效果架构成立，四缺口（C1 RL 期指认 / C2 分解消融 / C3 操作化 / C4 池外守门）修后即为完整证据链。

## 4. 工作量评估（是否偏离 9~11 人·天）

### 裁定：上调到 12~15 成立，理由充分；附 3 项修正 + 封顶
1. **上调理由成立**：9~11 只买到"效果达标"（M0-M3 技术正确落地），买不到三目标包装。新增 3~4 人·天几乎全是实验/包装（C2/C3 消融复用训练产物、C5 复用资产、C1 复用 A1），边际成本远低于论文+开源收益 ✅ 草案 §8 理由 1/2 成立。

3. **C6 预算修正**：0.5~1 人·天**偏紧且依赖关系有误**。C6 攻守权衡（可解释 EV 分解）与 C4 剥削（对手池/风格）共享度有限，实际共享点只有"攻守权衡头"一处。修正：C6 改为与 **C2 危险度因子共享**（同属解释链）+ 单列 1 人·天（explain.py 扩展 + predict 对接 + JSON schema 验证）。
4. **封顶纪律**：总预算硬上限 15 人·天，超限触发 §8 裁剪顺序（已承诺）；裁剪底线 = C1-C3 消融（1.5 人·天）✅ 与我 R5 一致。
5. **并行安排确认**：创新打包与 M0/M1 并行不阻塞主训练 ✅ 正确。

**工作量总评**：12~15 是"三目标版"的正确预算；9~11 是"效果达标版"的预算，两者目标不同不可直接对比。按上述修正后接受 12~15（封顶 15）。
