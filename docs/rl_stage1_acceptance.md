## 2. 实测证据

1. **smoke 实跑**（--event-attn，CPU）：1 局 304 步通过；lp≈-3.9e-9、lv=68.7、H=0.055、ratio.mean=1.0。lv 远大于 lp → 奖励/价值尺度不匹配实证（§2.4 的 value 尺度问题真实存在，未处理）。
2. **logp 一致性合成测试**：声明阶段 pon+chow 双选项（pon logit 0.8 / chow -0.5）时，采样归一化分布 {pass .153, pon .547, chow .300}，重放 _logp_for_action(pon) 隐含概率 .690 → **初始 ratio=1.26≠1**。单选项时一致（本次 340 步对局未触发多选项，故均值恰为 1.0）。
3. **ckpt 比对**：value_pretrain.pt 与 transfer_final.pt 主干逐参数相等（stem/blocks diff=0），仅 value.* 不同 → 评审风险 #11 实际已由构造保证等价，但 arch §7.1 描述机制（transfer+覆盖）与代码（整网加载 value_pretrain.pt）不一致，未核实说明。
