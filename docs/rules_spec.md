## 10. 修订 v1.9（2026-08-26，回放验证修复）

- **引擎 `_resolve_action` 红五/普通五身份保持**（修复前：弃牌/立直用 pai 字符串解析时，
  若手牌无该精确副本则任意替换同种类牌，可能把普通 5m 换成红五 16，多算 1 番赤ドラ，

  1) sc-gains 按轮种分账（hora 减押金 / ryuukyoku 直比）；
  2) reach_accepted(step2) 计入 actions 并作押金计数与立直喂入依据（step1 仅宣言）；
  3) 宣言牌被鸣走/荣和（无 step2）→ 按普通弃牌喂入、不扣押金；
  4) claim 窗口出现「同座位的自摸 hora」→ 先过再摸；
  5) claim 队头与 oracle 动作种类不一致（如弃荣和取碰）→ 先 pass 跳过队头；
  6) `_resolve_held` 消耗牌保持红/普通身份。

  剩余 2.4% 为已知边缘类：desync:ryukyoku 48、illegal riichi 26、delta:hora 8（kan-dora/七对子边角）、
  desync:hora 2、3 局文件级解析异常（all-4-copies）。

## 5. 点数计算规格（用户定稿 v1.5，2026-08-25）

记 a 为基础点数，m 为符数，n 为翻数。

### 5.1 支付倍数
- 庄家和得 6a：荣和由放铳者付 6a；自摸则每家付 2a。
- 闲家和得 4a：荣和由放铳者付 4a；自摸则闲家付 a、庄家付 2a。
- 支付点数向上取整百。

### 5.2 一、若 n ≤ 4：a = m × 2^(n+2)，a ≥ 2000 取 a=2000（满贯）

符数 m 计算：
- 特殊牌型：七对子 m=25；平和自摸 m=20；有副露的"平和"形 m=30。
- 其他：底符 20 + 以下累加：
  1. 雀头和刻杠：役牌雀头（场风/自风/三元）+2，同时为场风自风 +4；明刻 +2、暗刻翻倍、幺九再翻倍；明杠 +8、暗杠翻倍、幺九再翻倍。
  2. 和牌形式：单骑/边张/嵌张听 +2；自摸 +2；门前清荣和 +10。
- 除七对子=25 外，最终 m 向上取整十。

### 5.3 二、若 n > 4（档位）
- n=5 → a=2000（满贯）；n=6-7 → 3000（跳满）；n=8-10 → 4000（倍满）；n=11-12 → 6000（三倍满）；n≥13 → 8000（役满）。

### 5.4 本场费与立直棒
- 本场费：本场数 N，荣和由放铳者全付 300N；自摸每家付 100N。
- 场上立直棒归和牌者。

### 5.5 役牌雀头口径（D1 定稿）
- **役牌/连风对子不计役种、不计番数**；仅计符（+2/+4，见 5.2）。
- 仅"刻子形态（3 张）"才计算役牌役。

## 1. 抢杠（chankan）
- 加杠（明杠 shouminkan）：**只要听这张牌的玩家即可抢**（任意役种、普通荣和判定）。
- 暗杠（ankan）：**任何人不可抢**（含国士无双；v1.7 修订，见 §8）。
- 振听玩家（三类振听任一）不得抢杠。

## 2. 同巡振听（temporary furiten，雀魂口径）
- 触发：未立直玩家，他家打出的牌**能完成其手牌形状（与有无役无关）**，且该玩家未荣和（pass 或改吃/碰/杠）→ 置同巡振听。
- 解除：该玩家下一次**摸牌**时解除；若在摸牌前**鸣牌**（吃/碰/杠），鸣牌时即解除。
- 立直玩家见逃任何可和牌 → 同巡 + 永久立直振听（不可解除）。
- 依据：百度百科"振听"词条（引 riichi.wiki 与雀魂官方教程《猴子也能学会的雀魂麻将教学》）：判断"所听之牌"仅基于和牌形态、与起和番数无关。

## 3. 西入（west extension）
- 南4 结算后：任一人分数 < 0 → 立即终局（飞人）；否则若所有人分数均 < 30000（且无人为负）→ 进入西1 继续，之后每局结束按同一条件判定；否则终局。
