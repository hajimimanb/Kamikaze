# RL 路线与创新评估（留档，2026-08-26）

## 0. 结论摘要
- 采用三阶段路线：**RL 强化（阶段1）→ 防守读牌（阶段2）→ 剥削性打法（阶段3）**
- 训练前完成所有代码/数据/评估准备，再启动 RL 训练
- 验收标准：每个阶段对上一阶段基线自对弈胜率 **≥ 66%**

## 3. 三阶段路线
```
阶段0（已有）: SL 77.28% + 7 头 + 校准阈值（tsumo 0.86 / kyushu 0.83）
阶段1: 7 头校准策略 + 事件因果注意力② + 对手池 RL
   验收: 对 SL 基线自对弈胜率 ≥ 66%
阶段2: 信念注意力 danger head ③（输入=自家手牌 mask 的公开信息，
   标签=他家听牌/危险度，自对弈 ground truth + 多对手混合数据）
   → 风险加权弃牌（防守读牌）
   验收: 对阶段1 放铳率下降 + 胜率不降
阶段3: 风格条件化策略 ①（对手风格摘要 FiLM + 风格化对手池）
   读牌同时用于防守（避铳）与进攻（对手不防铳→追大）
   验收: 对风格化对手池胜率提升 + 对基线不降
阶段4: 整合 + 天凤/固定评估协议验证
```

## 4. 关键决策（用户拍板）
- D1: RL 验收 = 对 SL 基线自对弈胜率 ≥ 66%
- D2: 读牌数据 = 自对弈手牌（ground truth）+ 数据集 mask 自家手牌（输入不含自家手牌）
- D3: 不做反事实价值学习（自举风险）作为主路线；专注 ①②③
- D4: RL 训练前完成全部准备工作；重要决策先汇报
